# PREM'S JARVIS
A responsive Jarvis-style AI web assistant built with vanilla HTML/CSS/JS and a Vercel serverless API.

## Deploy
1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Add environment variable `OPENAI_API_KEY` in Vercel Project Settings.
4. Optionally set `AI_MODEL`.
5. Deploy. Vercel gives you a public HTTPS link that works on phones.

Do not put your OpenAI API key in `public/index.html`.
